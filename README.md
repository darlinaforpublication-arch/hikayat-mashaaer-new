# حكايات ومشاعر

تطبيق عربي لإدارة الحكايات التفاعلية للأطفال ومتابعة تعلمهم العاطفي.

## التقنيات
- Next.js 15 / React 19
- Supabase Auth + PostgreSQL + Row Level Security
- Vercel deployment

## الإعداد
انسخي ملف env.example إلى .env.local وضعي رابط Supabase ومفتاح Publishable أو anon في المتغيرات. لا تضعي أبدًا مفتاح service_role في المتصفح أو داخل GitHub.

## الأدوار
- المشرفة: إدارة حسابات الأطفال، مكتبة القصص، تخصيص القصص ومتابعة التقدم.
- الطفل: مشاهدة القصص المخصصة له فقط، والإجابة مع حفظ التقدم.

يستخدم التطبيق قاعدة Supabase الحالية hikayat-mashaaer-new والجداول والإجراءات المخزنة الموجودة بالفعل. لا ينشئ أو يحذف بيانات القاعدة عند تشغيل الموقع.
